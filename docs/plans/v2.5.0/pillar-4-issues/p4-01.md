# [v2.5.0][P4-01] Audit frontend, canonical design references, and approved assets

**Parent epic:** [Pillar 4 — #21](https://github.com/Robotti-io/Meshcore-Observer/issues/21)
**Type:** Research
**Stage:** Issue scoped; implementation planning pending.

## Outcome and scope

- Inventory current dashboard views, interaction patterns, accessibility/performance gaps, and reusable vanilla frontend seams.
- Confirm authoritative Robotti design-system references, approved logo/icon/font assets and licenses, and the current Chart.js/CDN/offline behavior.
- Recommend lightweight integration options and identify decisions requiring approval; distinguish canonical brand rules from Observer product extensions.

## Dependencies

No child prerequisite. Begin with this scoped research/decision work.

Dependencies identify required evidence/interfaces for implementation. They do not require finishing an entire consuming/owning epic before independent planning. Existing shared services retain their owning issue.

## Acceptance criteria

- [ ] Evidence links and a current frontend inventory identify concrete gaps and reuse opportunities.
- [ ] Approved assets and unsupported/unknown brand or browser assumptions are explicit.
- [ ] No new framework, package, external asset, CSP, or canonical brand rule is introduced by this research.

## Validation expectations

Review local frontend/tests and authoritative design/asset sources; document proposed representative-browser and dataset checks.

## Existing seams and approval boundaries

src/web frontend, existing tests, static assets, design-system sources.

Follow AGENTS.md: JavaScript ES modules, centralized strict AJV/configuration/logging, existing seams, and always-on MetricsStore ownership. Concrete authentication, storage, public API/MQTT, dependency, logging-contract, CSP, and deployment changes require explicit approval in the implementation plan. Real hardware, service, privilege, restart, or network operations require the applicable authorization; issue capture performs none.
