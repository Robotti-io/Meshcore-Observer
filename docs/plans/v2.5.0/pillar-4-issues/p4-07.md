# [v2.5.0][P4-07] Standardize tables, filters, search, and long identifiers

**GitHub issue:** [#44](https://github.com/Robotti-io/Meshcore-Observer/issues/44)
**Labels:** `release:v2.5.0`, `pillar:ui-ux`, `enhancement`

**Parent epic:** [Pillar 4 — #21](https://github.com/Robotti-io/Meshcore-Observer/issues/21)
**Type:** Feature
**Stage:** Issue scoped; implementation planning pending.

## Outcome and scope

- Provide consistent table headers, alignment, local scrolling, sorting/filter/search/result count conventions where useful.
- Make filter scope and reporting-range behavior explicit, preserving full values for long names/keys/paths.
- Keep tables bounded and safely render untrusted labels.

## Dependencies

- [P4-02 — #39](https://github.com/Robotti-io/Meshcore-Observer/issues/39)
- [P4-04 — #41](https://github.com/Robotti-io/Meshcore-Observer/issues/41)

Dependencies identify required evidence/interfaces for implementation. They do not require finishing an entire consuming/owning epic before independent planning. Existing shared services retain their owning issue.

## Acceptance criteria

- [ ] Similar tables behave consistently; page/current dataset/server query scopes are labeled.
- [ ] Long values do not break layout and can be revealed/copied accessibly where useful.
- [ ] Search/filter/sort preserves exact displayed meanings and existing security behavior.

## Validation expectations

Meaningful filter/sort/escaping tests plus large-table/narrow/focus checks; npm test and npm run lint.

## Existing seams and approval boundaries

Client table/search helpers and existing query consumers.

Follow AGENTS.md: JavaScript ES modules, centralized strict AJV/configuration/logging, existing seams, and always-on MetricsStore ownership. Concrete authentication, storage, public API/MQTT, dependency, logging-contract, CSP, and deployment changes require explicit approval in the implementation plan. Real hardware, service, privilege, restart, or network operations require the applicable authorization; issue capture performs none.
