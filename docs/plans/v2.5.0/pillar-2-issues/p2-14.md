## Outcome and scope

- Build the approved guided Linux/Raspberry Pi installation artifact/entry point for documented architectures.
- Validate supported runtime/native serial/prerequisites and separated code/config/data layout.
- Provide actionable failures and preserve existing installation/configuration/history during upgrades.

## Acceptance criteria

- [ ] Supported Linux/Pi operators have a guided first-run path without manual config/example copying.
- [ ] Architecture/runtime/permission assumptions and unsupported targets are clearly documented.
- [ ] Container and manually supplied environment operation remain compatible; no unapproved packaging dependency/CI change is added.

## Validation expectations

Supported architecture/install/upgrade/missing prerequisite fixtures and authorized Linux/Pi verification.

Approved packaging/runtime layout and repository-defined workflows.

Real hardware, service, privilege, restart, or network operations require the applicable authorization; issue capture performs none.
