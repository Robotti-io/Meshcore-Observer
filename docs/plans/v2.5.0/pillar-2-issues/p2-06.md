# [v2.5.0][P2-06] Build guided onboarding, review, and resumable setup

**GitHub issue:** [#71](https://github.com/Robotti-io/Meshcore-Observer/issues/71)
**Labels:** `release:v2.5.0`, `pillar:simplified-setup`, `enhancement`, `configuration`, `security`

**Parent epic:** [Pillar 2 — #19](https://github.com/Robotti-io/Meshcore-Observer/issues/19)
**Type:** Feature
**Stage:** Issue scoped; implementation planning pending.

## Outcome and scope

- Provide a progressive local wizard with required versus advanced steps, concise help, validation, review summary, and activation feedback.
- Persist only approved local draft state with a defined lifecycle/resume behavior and no accidental production activation.
- Reuse Pillar 4 controls/focus/status patterns and keep stored secret values out of browser persistence and review screens.

## Acceptance criteria

- [ ] Normal flow explains settings without requiring environment variable or JSON knowledge.
- [ ] Incomplete setup can resume safely; drafts remain distinct from active configuration.
- [ ] Keyboard progress/focus, responsive forms, and secret-safe review/validation states work under interruptions.

## Validation expectations

Wizard state/resume/review/validation tests and manual keyboard/narrow-screen checks; npm test and npm run lint.

## Existing seams and approval boundaries

Setup page/client/shared controls and approved local draft storage.

Follow AGENTS.md: JavaScript ES modules, centralized strict AJV/configuration/logging, existing seams, and always-on MetricsStore ownership. Concrete authentication, storage, public API/MQTT, dependency, logging-contract, CSP, and deployment changes require explicit approval in the implementation plan. Real hardware, service, privilege, restart, or network operations require the applicable authorization; issue capture performs none.
