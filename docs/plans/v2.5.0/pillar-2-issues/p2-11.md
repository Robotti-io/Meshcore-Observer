# [v2.5.0][P2-11] Export and import configuration with explicit secret handling

**GitHub issue:** [#76](https://github.com/Robotti-io/Meshcore-Observer/issues/76)
**Labels:** `release:v2.5.0`, `pillar:simplified-setup`, `enhancement`, `configuration`, `security`

**Parent epic:** [Pillar 2 — #19](https://github.com/Robotti-io/Meshcore-Observer/issues/19)
**Type:** Feature
**Stage:** Issue scoped; implementation planning pending.

## Outcome and scope

- Define and implement approved versioned portable non-secret configuration backup/export and restore/import.
- Validate all imported metadata/settings using current authoritative rules and explain migration or required credential re-entry.
- Keep configuration backup distinct from metrics/history backup and avoid implicit plaintext secret export.

Dependencies identify required evidence/interfaces for implementation. They do not require finishing an entire consuming/owning epic before independent planning. Existing shared services retain their owning issue.

## Acceptance criteria

- [ ] Ordinary exports exclude secret values and describe preserved references/missing credentials.
- [ ] Malformed/older/untrusted imports are validated before activation and known-good state is retained.
- [ ] Scope/version/path validation and safe apply/recovery prevent unintended writes or partial restores.

## Validation expectations

Round-trip, invalid/older metadata, secret redaction, unsafe paths, failed import/activation tests; npm test and npm run lint.

## Existing seams and approval boundaries

Setup import/export APIs, schemas, safe configuration activation.

Follow AGENTS.md: JavaScript ES modules, centralized strict AJV/configuration/logging, existing seams, and always-on MetricsStore ownership. Concrete authentication, storage, public API/MQTT, dependency, logging-contract, CSP, and deployment changes require explicit approval in the implementation plan. Real hardware, service, privilege, restart, or network operations require the applicable authorization; issue capture performs none.
