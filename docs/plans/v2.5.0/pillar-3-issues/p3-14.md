## Outcome and scope

- Run integrated targeting/suppression/private/ACK/scoped radio checks under agreed budgets and representative mixed workloads.
- Verify Unicode, competing replies, scope transactions, bounded retries, persistent recovery, and existing configuration/handler compatibility.
- Document operator targeting, private ACK semantics, scope/fallback/retry settings, supported versions, and RF implications.

## Acceptance criteria

- [ ] Repository regression checks pass and authorized multi-bot/hardware evidence is recorded.
- [ ] No observed response storms, scope races, cross-attributed ACKs, or capture/starvation regression remains unexplained.
- [ ] Run/environment/budget limitations and scoped follow-up defects are explicit.

## Validation expectations

npm test and npm run lint plus separately authorized RF/restart/connection scenarios; issue capture performs no live checks.

## Existing seams and approval boundaries

Bot/radio/store test fixtures and operator guidance.

Follow AGENTS.md: JavaScript ES modules, centralized strict AJV/configuration/logging, existing seams, and always-on MetricsStore ownership. Concrete authentication, storage, public API/MQTT, dependency, logging-contract, CSP, and deployment changes require explicit approval in the implementation plan. Real hardware, service, privilege, restart, or network operations require the applicable authorization; issue capture performs none.
