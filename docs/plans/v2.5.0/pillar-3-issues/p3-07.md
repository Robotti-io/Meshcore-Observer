# [v2.5.0][P3-07] Resolve per-command region scopes and explicit fallback policy

**GitHub issue:** [#58](https://github.com/Robotti-io/Meshcore-Observer/issues/58)

**Parent epic:** [Pillar 3 — #20](https://github.com/Robotti-io/Meshcore-Observer/issues/20)
**Type:** Feature
**Stage:** Implemented in the current branch; validation recorded in the parent plan.

## Current branch baseline

Channel bots accept a string `regionScope` to fix every reply to one public
region, or an array of names to allow only matching scoped commands and mirror
their incoming region. The array also supplies known names for resolving that
bot's commands; unscoped commands and out-of-list regions are skipped. With no
bot setting, commands mirror a resolvable incoming scope using discovery and
`PACKETCAPTURE_REGION_SCOPES`; unknown or ambiguous scoped commands are skipped.
The observer-wide setting is a case-sensitive comma-separated list known to
all bots. Replies still use flood routing.

The implementation adds explicit per-command `scope` and `fallback` policies
while retaining the baseline for omitted or `inherit` scope. Policies are
validated at config load, snapshotted on durable queued replies, and checked
against current bot constraints before dispatch. Regional fallback is
available only after a pre-send scope-apply failure. A fallback is never used
after a send attempt. The current Companion API cannot perform explicit
unscoped sends, so those policies fail closed without transmission.

## Outcome and scope

- Validate semantic region identifiers and command/bot inheritance using the approved OKI/protocol mapping.
- Represent default, regional, and unscoped modes explicitly, preserving case/wildcard meanings as verified.
- Persist intended policy and define fail/defer/retry/explicit fallback without deriving authorization from OBS-02 declarations.

## Acceptance criteria

- [x] Invalid scope configuration fails at config load; unresolved inherited incoming scopes are skipped.
- [x] Human-facing names resolve through the established case-sensitive transport-key mapping; OKI names are not hard-coded into the core.
- [x] Required scopes do not silently become broader floods, including restart/config changes; explicit fallback is persisted and constrained.
