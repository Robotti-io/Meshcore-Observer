# [v2.5.0][P3-04] Match Unicode bot tags and command-level targeting configuration

**GitHub issue:** [#55](https://github.com/Robotti-io/Meshcore-Observer/issues/55)
**Labels:** `release:v2.5.0`, `pillar:enhanced-bots`, `enhancement`, `configuration`

**Parent epic:** [Pillar 3 — #20](https://github.com/Robotti-io/Meshcore-Observer/issues/20)
**Type:** Feature
**Stage:** Issue scoped; implementation planning pending.

## Outcome and scope

- Implement the approved tag syntax and per-command targeting metadata using central strict configuration schemas.
- Separate tag, whitespace, trigger, and arguments safely, with escaped/literal matching rather than unsafe dynamic regex construction.
- Preserve existing untagged behavior and ignore malformed/wrong-bot targeting.

## Acceptance criteria

- [ ] Only the intended approved identity match executes target-required commands; duplicate-name limitations remain explicit.
- [ ] Emoji, normalization/case rules, length limits, whitespace, and argument-like tags are covered.
- [ ] Legacy command definitions continue working and invalid policy fails before side effects.

## Validation expectations

Command parsing/configuration and adversarial tag/Unicode fixtures; npm test and npm run lint.
