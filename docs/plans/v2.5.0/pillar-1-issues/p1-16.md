## Acceptance criteria

- [ ] Repository tests/lint and meaningful regression scenarios pass with reproducible evidence.
- [ ] Authorized hardware/RF checks demonstrate conservative discovery/telemetry and no observed scope leaks, request cross-correlation, or runaway retries.
- [ ] Baseline comparison, dataset size, run duration, restart gaps, and measurement limitations are recorded.
- [ ] Existing metrics/pending replies/registry/advert state are preserved through migration and recovery.
- [ ] Operational guidance explains opt-in behavior, supported versions, safe secret handling, broker/CoreScope requirements, and unavailable data.
- [ ] In an authorized isolated test with no internet or broker availability, local radio capture, verified inventory/history, lookup and local insight reads continue; restart preserves learned data. Exercise full/locked storage, interrupted migration, pruning failure and reconnect recovery, verifying explicit failures and no silent loss of saved evidence.
