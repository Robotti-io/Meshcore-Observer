Targeting, suppression, scoped delivery, and private/ACK work proceed through their explicit dependencies; topology assistance remains a research decision rather than an assumed route.

Dependencies link specific owning issues rather than duplicating their work. Publication/issue-number order is not a requirement to implement features sequentially. Independent planning can use approved interfaces; final integration and validation must satisfy the listed dependencies.
